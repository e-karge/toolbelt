darkhttpd
=====

Docker image for [darkhttpd](https://unix4lyfe.org/darkhttpd/). To use run

```bash
docker run --rm -ti toolbelt/darkhttpd
```

See [here](https://linuxcommandlibrary.com/man/darkhttpd) for invocation details.
